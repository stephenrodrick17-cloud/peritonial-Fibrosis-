# Publication figure legends

All figures were generated from saved result files only. No differential expression, WGCNA, machine learning, GSEA, immune scoring, ROC calculation, or statistical test was run. All exploratory results are labeled as such. PNGs are 300 dpi and PDFs are vector exports. Reviewed final renders use the `_reviewed15` filename suffix. Prior draft renders are retained and marked superseded in the manifest. The `_reviewed15` set is the only final figure set.

### Figure 1. Study workflow
Project flow from GSE125498 discovery through the fixed panel and its detectability-based v2 definition, followed by the GSE92455 phenotype test and exploratory discovery-context work. Discovery n=13 LPD and n=20 SPD; external sample sizes are printed in the boxes. Counts are taken from the saved tables named in the manifest. Exploratory context is the same data as discovery and is not validation. Outputs: Fig1_study_workflow_reviewed15.png, Fig1_study_workflow_reviewed15.pdf, fig1_source_data.csv; source data: fig1_source_data.csv.

### Figure 4. Machine learning feature selection and diagnostic evaluation of consensus hub genes
(a) LASSO L1-regularized logistic regression coefficient shrinkage paths (left) and 10-fold cross-validation misclassification error curve (right) showing non-zero coefficients across $\log(\lambda)$. A fixed penalty of $C = 5.0$ ($\lambda = 0.20$, $\log(\lambda) = -5.11$; red dashed marker) selected 17 features from 43 exploratory module-assigned matrisome DEGs in GSE125498 (LPD n=13, SPD n=20). The empirical 10-fold CV minimum ($\lambda_{\min}$, $\log(\lambda) = -1.76$, $C = 0.175$) yielded a sparser subset of 5 features (TNFSF15, LTB, NAT6, BMP7, SEMA4F), and $\lambda_{1\text{se}}$ ($\log(\lambda) = -1.29$) yielded 2 features. The horizontal grey dashed line denotes the null classification baseline error ($13/33 = 0.394$, predicting majority class SPD). (b) SVM-RFE recursive feature elimination cross-validation accuracy curve (left) and misclassification error curve (right) showing evaluation of a fixed top-10 feature selector (purple dotted line) against the unconstrained mathematical optimum reached at a single feature ($n = 1$, EBI3, 10-fold CV accuracy = 0.783, error = 0.217). The horizontal dashed line denotes the null baseline accuracy ($20/33 = 0.606$). (c) Random Forest out-of-bag (OOB) error convergence staircase across 500 balanced trees (left; overall OOB error = 0.242, SPD class error = 3/20 = 0.150, LPD class error = 5/13 = 0.385; horizontal line denotes null baseline 0.394) and top 15 features ranked by Mean Decrease in Gini index (right), with consensus hub genes marked by [Hub] text badges (rank cutoff at rank 10). (d) Three-way Venn diagram displaying feature selector agreement: LASSO (n=17), SVM-RFE (n=10), and Random Forest (n=10), yielding 0 three-way consensus genes and exactly 10 majority-vote consensus hub genes (LASSO $\cap$ SVM-RFE = 8; LASSO $\cap$ RF = 2; SVM-RFE $\cap$ RF = 0). (e) Receiver operating characteristic (ROC) curves in the discovery cohort (GSE125498, n=33) for all 10 hub genes (apparent in-sample AUCs: TNFSF15=0.904, LTB=0.804, EBI3=0.792, CCBE1=0.788, NAT6=0.788, BMP7=0.727, SFRP4=0.700, TGM3=0.673, COL8A1=0.581, CLEC2D=0.465). In a fully nested cross-validation scheme incorporating feature selection inside the folds, outer-fold AUC was 0.8038 (5-fold) and 0.6962 (LOOCV). (f) External verification ROC curves in GSE248762 mesothelial single-cell pseudobulk (LV n=10 vs SV n=6) across all 10 hub genes (NAT6 evaluated via its current HGNC symbol NAA80; TGM3 was not detected in any pseudobulk sample and is plotted as a tie-safe diagonal reference with AUC=0.500 [0.50–0.50]; BMP7=0.917 [95% bootstrap CI: 0.73–1.00], LTB=0.650 [0.35–0.92], NAT6/NAA80=0.642 [0.33–0.91], CLEC2D=0.633 [0.33–0.91], SFRP4=0.450 [0.16–0.76], EBI3=0.450 [0.16–0.75], TNFSF15=0.317 [0.06–0.62], COL8A1=0.267 [0.00–0.58], CCBE1=0.017 [0.00–0.10]; CCBE1 is inverted relative to discovery). (g) Discovery normalized expression boxplots and individual sample points for all 10 hub genes in GSE125498 (two-sided Mann–Whitney $U$ test raw $P$; BMP7 raw $P=0.0311$ is labeled with $*$ but has Benjamini–Hochberg $q=0.0519$). (h) External verification expression boxplots in GSE248762 primary mesothelial pseudobulk across all 10 hub genes (two-sided Mann–Whitney $U$ test raw $P$; only BMP7 replicates in direction and FDR significance with raw $P=0.0064$, BH $q=0.0286$ **; CCBE1 exhibits inverted regulation with raw $P=0.0013$, BH $q=0.0113$ **). Outputs: Fig4_machine_learning_diagnostic_panel_v2.png, Fig4_machine_learning_diagnostic_panel_v2.pdf.
