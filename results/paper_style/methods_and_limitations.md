# Methods and Limitations

## Methods

### Dataset Acquisition and Preprocessing
Discovery microarray data from GSE125498 were acquired from the Gene Expression Omnibus (GEO). The dataset contains 33 peritoneal dialysis effluent cell pellet samples: 13 long-term PD cases ($\ge 48$ months) and 20 short-term PD controls ($< 12$ months) profiled on the Illumina HumanHT-12 v4 Expression BeadChip (GPL10558). Raw bead intensities were background-corrected, variance-stabilized, and quantile-normalized. Multiple probes mapping to the same gene symbol were summarized using the maximal mean expression method (`collapseRows`, maxMean), yielding a definitive background universe of 11,741 unique annotated genes. External datasets included human parietal peritoneal biopsies from GSE62928 (Affymetrix HG-U133 Plus 2.0; 4 severe encapsulating peritoneal sclerosis [EPS] cases vs 4 non-EPS controls) and peritoneal effluent samples from GSE248762 (single-cell RNA-seq pseudobulk; 10 long vintage vs 6 short vintage) and GSE130888 (bulk RNA-seq; 4 long vintage vs 6 short vintage). Cohorts were analyzed independently; no cross-cohort merging or batch pooling was conducted.

### Differential Expression Analysis
Differential expression analysis between LPD and SPD was performed using empirical Bayes linear modeling via the `limma` package (v3.62.2) in R (v4.4.2). The primary screening threshold was set at $|\log_2\text{fold change}| \ge 0.585$ (corresponding to a 1.5-fold difference) and nominal $P < 0.05$. Multiple testing was controlled using the Benjamini–Hochberg (BH) false discovery rate method across the full 11,741-gene universe. Hierarchical clustering of the top 50 DEGs was performed using complete linkage and Euclidean distance on row-standardized $z$-scores.

### Functional Enrichment and Gene Set Analysis
Gene set enrichment analysis (GSEA) was conducted using `clusterProfiler` (v4.14.4) and `gseapy` (v1.3.1). Preranked GSEA utilized moderated $t$-statistics from the limma output mapped to Entrez Gene IDs via `org.Hs.eg.db` (v3.20.0). Pathways from the Kyoto Encyclopedia of Genes and Genomes (KEGG, 2024/2025 release) with minimum gene set size of 15 and maximum of 500 were evaluated across 1,000 permutations. Significance was defined at BH FDR $< 0.05$. Over-representation analysis (ORA) for Gene Ontology (GO) biological processes, cellular components, and molecular functions was evaluated with hypergeometric tests against the expressed background universe.

### Matrisome Overlap and Co-Expression Network Analysis (WGCNA)
The reference human matrisome gene list was obtained from the Naba Matrisome Project (comprising 1,027 core matrisome and matrisome-associated genes). Expressed matrisome genes in GSE125498 ($n = 428$) were intersected with primary DEGs. Statistical over-representation was evaluated via hypergeometric testing and 10,000 Monte Carlo label permutations. Weighted gene co-expression network analysis was conducted using the `WGCNA` R package (v1.73). Pearson correlation adjacency matrices were constructed using a signed network and a soft-threshold power of $\beta = 12$ on the top 5,001 most variable genes. Topological overlap matrices (TOM) were computed, and dynamic tree cutting (`dynamicTreeCut` v1.63-1) was applied with a minimum module size of 30. Module eigengenes (MEs) were correlated with PD duration using Pearson correlation.

### Machine Learning Feature Selection and Consensus Identification
Feature selection was conducted on the candidate exploratory pool of 43 module-assigned matrisome DEGs (GSE125498: 13 LPD cases, 20 SPD controls; standardized using `StandardScaler`; null baseline error = 13/33 = 0.3939 predicting majority class SPD) using three distinct machine learning algorithms implemented in `scikit-learn` (v1.6.1):
1. **LASSO Logistic Regression:** Evaluated across a regularized grid of $C$ values. A fixed penalty of $C = 5.0$ ($\lambda = 0.20$, $\log(\lambda) = -5.11$; `LogisticRegressionCV`, `solver='liblinear'`, `penalty='l1'`, `random_state=42`, `max_iter=5000`) selected 17 features with non-zero absolute coefficients. Unconstrained 10-fold cross-validation resolved an empirical $\lambda_{\min}$ at $\log(\lambda) = -1.76$ ($C = 0.175$) selecting 5 features, and $\lambda_{1\text{se}}$ at $\log(\lambda) = -1.29$ ($C = 0.111$) selecting 2 features.
2. **SVM-RFE:** A fixed top-10 feature selector was evaluated (`SVC(kernel='linear', random_state=42)` with step=1). Unconstrained 10-fold cross-validation with recursive feature elimination (`RFECV`) reached its global minimum misclassification error at a single feature ($n = 1$, EBI3, CV accuracy = 0.783). The top 10 ranked features were retained for multi-selector consensus intersection.
3. **Random Forest:** Random forest classification (`RandomForestClassifier`, 500 trees, `random_state=42`, `class_weight='balanced'`), evaluating out-of-bag error convergence across cumulative tree increments (overall OOB error rate = 0.242, SPD class error = 3/20 = 0.150, LPD class error = 5/13 = 0.385) and selecting the top 10 features ranked by Mean Decrease in Gini impurity.

Consensus diagnostic hub genes were defined by majority vote ($\ge 2$ of 3 algorithms), which yielded 10 hub genes (8 in LASSO $\cap$ SVM-RFE, 2 in LASSO $\cap$ Random Forest, and 0 in SVM-RFE $\cap$ Random Forest; strict 3-way intersection = 0). Feature stability was evaluated across 200 stratified bootstrap iterations. To assess unbiased generalizability free of feature selection leakage, a fully nested cross-validation pipeline (5-fold and LOOCV) was implemented, repeating feature scaling, all three selectors, consensus majority voting, and ridge model training strictly within training partitions.


### Diagnostic Model, Calibration, and Decision Curve Analysis
A reduced multivariable logistic regression model with ridge (L2) shrinkage was constructed using the 5 core diagnostic biomarkers. Discrimination was assessed using receiver operating characteristic (ROC) curves and the area under the curve (AUC) with 95% bootstrap confidence intervals ($B = 1,000$ iterations). Calibration was evaluated across 5 equal-count risk quintiles ($n = 6$ or $7$ per bin), comparing mean predicted probabilities against observed event rates with exact Clopper–Pearson binomial 95% confidence intervals. Optimism-corrected C-indices were derived from repeated 5-fold cross-validation (10 repeats). Decision curve analysis (DCA) and clinical impact curves were computed using apparent model predictions across threshold probabilities from $P_t = 0.01$ to $0.99$.

### Immune Microenvironment Deconvolution
Relative infiltration levels of 13 leukocyte and stromal cell populations were estimated using single-sample GSEA (ssGSEA) based on validated CellMarker 2024 and LM22 gene sets. Because effluent cell pellets contain shed mesothelial cells, leukocytes, and debris, these scores represent indirect relative enrichment proxies rather than absolute tissue cell counts. Group differences were evaluated with two-sided Mann–Whitney $U$ tests with BH-FDR correction across cell types. Immune-immune and gene-immune correlations were calculated using two-sided Spearman rank tests. For the seven-gene, 13-cell-type panel, BH-FDR was applied jointly across all 91 gene-cell-type tests; Panel G significance symbols denote these adjusted q values.

### Pharmacogenomics, Functional Networks, and Molecular Subtyping
Functional association networks were reconstructed using the GeneMANIA algorithm (automatic network weighting, 20 additional interactors). The seven validated hub genes (TNFSF15, FLT3LG, EBI3, LTB, ADAM19, ECM1, and CST7) were submitted as a gene set to the DSigDB v1.0 library through Enrichr for over-representation analysis. Benjamini–Hochberg adjusted P values were used to assess significance ($q < 0.05$); nominally enriched terms overlapping at least two input genes were retained only for exploratory display. This gene-set analysis tests overlap with curated perturbation signatures; it does not estimate reversal of the LPD expression profile.

For hub-specific pathway analysis, each of the seven genes was analyzed separately. All 11,741 measured genes were ranked by their Spearman correlation with the corresponding hub-gene expression across the 33 GSE125498 samples. Preranked GSEA was performed against 320 human KEGG pathways using GSEApy, 1,000 permutations (seed 20261013), and gene-set sizes of 15–500. Benjamini–Hochberg FDR was controlled across the 320 pathways separately for each hub gene ($q < 0.05$); correction was not pooled across the seven hub-gene analyses. Positive NES indicates pathway genes enriched toward genes positively correlated with the hub, and negative NES indicates enrichment toward negatively correlated genes. These within-cohort, post-selection associations are exploratory and do not by themselves indicate LPD-versus-SPD pathway direction or causal regulation.

For the overall LPD-versus-SPD running-enrichment visualization, all 11,741 unique measured gene symbols were ranked by their limma moderated $t$-statistics (positive values indicate higher expression in LPD). GSEApy preranked GSEA tested 320 cached human KEGG pathways (15–500 genes) using 1,000 permutations (seed 20261016); BH-FDR was controlled across all 320 pathway tests. The running curves use the full ranked list and all ranked members of each pathway. This symbol-based rerun supports complete hit positions and running scores and is distinct from the previously saved Entrez-based KEGG results table. The analysis is exploratory and limited to the discovery cohort.

Unsupervised consensus clustering was performed on the 13 LPD samples using the diagnostic gene panel across 1,000 iterations (80% item subsampling, complete linkage on consensus distance matrices). Optimal cluster number was evaluated using consensus CDF curves, delta area under the CDF, and the proportion of ambiguous clustering (PAC). Differences in gene expression and immune infiltration between molecular subtypes were assessed via two-sided Mann–Whitney $U$ tests.

## Limitations

Several material limitations must be emphasized:
1. **Small Discovery Cohort and Low Events-per-Variable:** The discovery cohort GSE125498 comprises 33 patients with only 13 LPD events. Fitting multi-predictor diagnostic models (5 or 7 predictors) under low events-per-variable ($13/5 = 2.6$) introduces known risk of model over-fitting and optimism in unpenalized estimates. While ridge regularization and bootstrap resampling were applied, in-sample performance metrics remain exploratory and hypothesis-generating.
2. **Effluent vs. Biopsy Biology:** Peritoneal dialysis effluent contains shed peritoneal cells, infiltrating inflammatory leukocytes, and ambient debris. Biomarker signatures measured in effluent reflect luminal shedding, microenvironmental inflammation, and membrane turnover, which differ fundamentally from the structural collagenous architecture of parietal peritoneal biopsies. In the GSE62928 biopsy cohort, operational expression cutoffs were not met, precluding direct tissue confirmation.
3. **External Effluent Validation Constraints:** External effluent cohorts (GSE248762, GSE130888) involved small sample sizes ($N = 16$ and $N = 10$, respectively), differing quantification platforms (single-cell pseudobulk vs. bulk RNA-seq), and absent patient crosswalk data to rule out overlapping donor identity. Furthermore, one key biomarker (SERPINA10) showed negligible counts in single-cell effluent libraries.
4. **Indirect Immune Deconvolution:** Microenvironmental ssGSEA scores are relative marker enrichment metrics, not flow-cytometry-verified cell proportions. Elevated ECM1 and cytokine signals may reflect monocyte/macrophage activation or ambient transcript accumulation rather than primary fibroblast-intrinsic remodeling.
5. **No Experimental Validation:** Wet-lab functional assays (*in vitro* mesothelial-mesenchymal transition or animal models of peritoneal sclerosis) were not performed; identified perturbational drugs and regulatory interactions represent *in silico* hypotheses.
